## How to sign

We use a lightweight sign-off. By adding a `Signed-off-by` line to your commits
you certify that you have read and agree to this Agreement and to the
[Developer Certificate of Origin](https://developercertificate.org/).

Add the line automatically with:

```bash
git commit -s -m "your message"
```

which appends:

```
Signed-off-by: Your Name <your.email@example.com>
```

For your **first** Contribution, please also add your name to
[`CONTRIBUTORS.md`](./CONTRIBUTORS.md) in the same pull request, or state in the
pull request description:

> I have read the CLA document and I hereby sign the CLA.

This constitutes your acceptance of this Agreement for all of your current and
future Contributions to the Project.
